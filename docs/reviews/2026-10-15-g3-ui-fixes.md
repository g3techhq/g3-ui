# g3-ui audit resolution

Implementation started October 15, 2026; final verification October 16, 2026.
This records working-tree changes against the [original audit](2026-10-15-g3-ui-audit.md).
No release or publication was performed.

## Confirmed defects

| Finding | Resolution |
| --- | --- |
| 1: overlay ordering | Shared top-layer presentation for dialogs, popovers and overlay sheets, with toast priority. Push/reveal sheets retain their page-layout relationship. |
| 2: tab touch capture | A shared WebView script waits for horizontal intent before capturing; taps reach nested buttons. |
| 3: native UTC defaults | Native date/time defaults use the device's local clock. |
| 4: disabled date confirmation | Wheel and calendar selections enforce bounds and the disabled-date predicate at confirmation. |
| 5: stale debounced clear | Clearing invalidates pending notifications; external value changes cannot emit the previous typed value. |
| 6: readonly clearing | Readonly fields suppress the clear action and reject mutating handlers. |
| 7: replacement tab state | Live tab context includes signal identity and follows replacement signals. |
| 8: stale effect props | Synced props/scoped scripts follow alert defaults, toast duration, picker bounds, sheet settings, refresh settings, and infinite-scroll margin. |
| 9: strip listener retention | Scoped DOM sessions dispose listeners, observers, animation callbacks and timers. |
| 10: below-backdrop trapping | Sheet focus trapping and scroll locking follow actual modality. |
| 11: unavailable calendar focus | Unavailable day buttons use aria-disabled and remain focusable; activation remains guarded. |
| 12: time wheel mismatch | Normalize the draft and commit to the displayed minute step, rounding down within the hour. |
| 13: cancelled refresh | Cancellation restores idle state without committing; pending refreshes and settlement timers are scoped. |
| 14: zoom restriction | AppWrapper preserves safe-area metadata and allows zoom. |
| 15: permissive time parser | Reject trailing colon-separated fields. |

## Additional improvements

- `OverlayController` exposes reactive `count()` and typed `dismiss_top()` for
  Android Back handling across overlay types.
- Retained tab panels are inert; horizontal tab lists leave Up/Down available
  for page scrolling. Mode propagation and current DOM animation order are fixed.
- Focus sessions handle nesting, hidden-page initialization and toast actions.
  Closing surfaces/backdrops cannot intercept input during exit animations.
- RTL swipe edges, rating pointer geometry and horizontal strip movement use
  logical directions.
- Images associate loading results with their source without render-time writes.
  Tooltip descriptions follow replaced triggers and release only owned attributes.
- Scoped script failures identify their call site in development. Script results
  return JSON null so normal disposal does not produce a false communication error.
- `reference_date` allows deterministic date markup across server/client time zones.
- Rating speech and date ordering are localized through Strings templates.
- README documents signal-driven forms, notification timing, compatibility
  capabilities, minute rounding and performance boundaries. See CHANGELOG for
  Strings-literal and RTL SwipeState migration details.

## Runtime limits and follow-up evidence

- No Android device/emulator was attached. Frame timing, memory, IME, rotation,
  background/resume, Back integration and TalkBack still require device testing.
  No performance speedup is claimed from compilation or source inspection.
- The standalone Playwright matrix and CI browser job were added. They include
  actual touch taps and screenshots, but that standalone runner was not executed
  in this session; browser interaction here used the available in-app browser API.
- The complete visual matrix was not repeated for every component or every
  gesture. Real touch dragging, all sheet detents, every RTL widget and WebKit/
  Firefox remain part of the [runtime guide](../testing.md).
- Consumer UI/service flows were not launched. Only the template's web target
  was checked; this does not certify every consuming app or platform.
- Dependency feature removal, virtualization and CSS/clone micro-optimizations
  remain measurement-driven design work. Known listener retention and unnecessary
  tab pointer bridge traffic were fixed; speculative rewrites were not introduced.

These limits do not represent remaining reproduced defects from findings 1–15.
They describe the evidence still needed for broad platform/performance claims.
